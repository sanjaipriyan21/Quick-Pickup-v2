🍔 Quick Pickup – Hotel Owner Dashboard

📌 Project Overview

Quick Pickup is a food ordering platform designed to simplify hotel operations through an interactive hotel owner dashboard, menu management, and order management system.

🚀 Today's Work & Features

1. Hotel Owner Dashboard

- Designed an interactive dashboard interface.
- Added total orders, total revenue, menu items, and pending orders.
- Added sales overview with graphical representation.
- Added recent activity and recent orders.
- Added popular food items section.

2. Menu Management

- Developed a food menu management interface.
- Added food images and item details.
- Organized menu items into a card-based layout.
- Added options to manage food items.
- Added an Add New Item interface.

3. Order Management

- Developed an order management screen.
- Added order details in a structured table.
- Added order status tracking.
- Included Pending, Processing, Completed, and Cancelled statuses.
- Added order summary cards.

4. UI Enhancements

- Added Light Mode and Dark Mode.
- Improved dashboard layout and navigation.
- Enhanced visual appearance and responsiveness.

🛠️ Technologies Used

- React.js
- JavaScript
- HTML
- CSS
